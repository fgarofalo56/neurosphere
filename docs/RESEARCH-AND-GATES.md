# Research evidence and unresolved implementation gates
This is a targeted evidence register, not a completed exhaustive research audit. No universal 'no gaps/no refactoring' certification is possible. Sources below were retrieved on the dates shown; verify again for the customer's deployment date. New evidence is filed through the `gate-evidence` issue template and lands here.
## Verified first-party findings
### Retrieved 2026-10-06
- Foundry Government feature-specific page lists prompt agents, function calling, Search and MCP but not every Commercial tool; workflows are preview. https://learn.microsoft.com/azure/foundry/agents/concepts/azure-government
- Platform Government page shows evaluations/optimization gaps and separate sovereign endpoints. https://learn.microsoft.com/azure/foundry/concepts/foundry-azure-government
- General Foundry region page and Government product roadmap returned conflicting/older coverage for agents compared with feature-specific page. Resolve with current product/agency evidence rather than choose the most favorable statement. https://learn.microsoft.com/azure/foundry/reference/region-support and https://learn.microsoft.com/azure/azure-government/documentation-government-product-roadmap
- Gremlin has traversal/parallelism/time limits, and cross-partition implications. Keep interactive queries bounded and benchmark before selecting optional graph engine. https://learn.microsoft.com/azure/cosmos-db/gremlin/limits and https://learn.microsoft.com/azure/cosmos-db/gremlin/partitioning
- Event Hubs metadata geo-DR does not copy event payloads or Entra RBAC; private endpoints need both-side configuration/testing. https://learn.microsoft.com/azure/event-hubs/event-hubs-geo-dr
- Foundry does not provide automatic application disaster recovery/failover. https://learn.microsoft.com/azure/foundry/how-to/high-availability-resiliency
### Retrieved 2026-10-08
- **Microsoft Fabric in GCC High**: public preview 2026-09-02, GA 2026-10-01, US Gov Virginia and US Gov Texas only; customer-managed keys, workspace identity and Fabric IQ items unsupported; FedRAMP High assessment in progress. GCC and DoD availability unverified. https://learn.microsoft.com/fabric/enterprise/us-government-community-cloud-high and https://www.microsoft.com/en-us/microsoft-cloud/blog/us-government/2026/09/02/microsoft-fabric-in-gcc-high-building-the-data-foundation-for-ai/. Availability is not authorization (G01/G02 stay open for Government Fabric).
- **Synapse and Azure Databricks** are in the Azure Government FedRAMP High / DoD audit scope (Synapse also IL6); Databricks in US Gov Virginia/Arizona. https://learn.microsoft.com/azure/azure-government/compliance/azure-services-in-fedramp-auditscope (updated 2026-09-21).
- **Azure AI Search**: in Government audit scope; semantic ranker, agentic retrieval and query rewrite available in US Gov Arizona/Virginia, not Texas; vector search availability in Government not stated on the regional table (unverified). https://learn.microsoft.com/azure/search/search-region-support (2026-10-01).
- **Foundry models in Azure Government** (usgovvirginia/usgovarizona, Data Zone Standard): gpt-5.x family, gpt-5.1, gpt-4.1/-mini (128K context cap), o3-mini, gpt-4o, text-embedding-3; Regional Standard lacks gpt-5.1 and o3-mini. Agent Service in Government: prompt agents, AI Search, MCP servers, function calling available; workflows preview; hosted agents, web search, Bing grounding, Fabric tool and agent-to-agent unavailable. https://learn.microsoft.com/azure/foundry/foundry-models/concepts/models-sold-directly-by-azure-gov (2026-09-01) and https://learn.microsoft.com/azure/foundry/agents/concepts/azure-government.
- **Event Hubs data geo-replication** is GA on Premium and Dedicated tiers only; Government support unverified. https://learn.microsoft.com/azure/event-hubs/geo-replication (2026-07-11).
- **Cosmos DB NoSQL**: hierarchical partition keys (up to 3 levels) carry no preview label, Python SDK ≥4.6, new containers only. https://learn.microsoft.com/azure/cosmos-db/hierarchical-partition-keys (2026-04-27). "All versions and deletes" change feed still requires a preview API version, continuous backup, and no prior partition merge; Python pull model only. https://learn.microsoft.com/azure/cosmos-db/change-feed-modes (2026-06-17). Projections therefore use an outbox, not this mode.
- **Azure Resource Graph** is in the Government audit scope (portal.azure.us, management.usgovcloudapi.net). Source as above, 2026-09-21.
- **Emulators**: Cosmos DB vNext Linux emulator GA June 2026 (no auth enforcement, no stored procedures/triggers/UDF, no range/composite/spatial indexes, no RU accounting, change feed supported). https://learn.microsoft.com/azure/cosmos-db/emulator-linux. Event Hubs emulator: SAS only, one namespace / ten hubs, no persistence across restarts, requires Azurite, GA status unverified. https://learn.microsoft.com/azure/event-hubs/overview-emulator (2026-08-26). Azurite Table API remains preview.
- **MCP**: current spec revision 2026-07-28; Python SDK 2.x and TypeScript SDK 2.x implement it; OAuth 2.1 resource-server auth (RFC 9728 protected-resource metadata) is in the SDK; `validate_token_resource` must be set explicitly; Dynamic Client Registration is deprecated; stdio transport is never authenticated. https://modelcontextprotocol.io/specification/versioning and https://py.sdk.modelcontextprotocol.io/.
- **Toolchain support windows**: Node 22 Maintenance until 2027-04-30 (Node 24 LTS to 2028-04-30); Helm 3 security fixes end 2027-02-10 (Helm 4 current); MkDocs Material EOL scheduled 2026-11-05 (successor Zensical); TypeScript 7 incompatible with typescript-eslint 8.71. Recorded in docs/adr/0002-stack-pins.md.
- **Vega** compiles expressions with the `Function` constructor by default and is not CSP-safe; `vega-interpreter` is the CSP-safe evaluator. https://vega.github.io/vega/usage/#csp. Chart plans from the copilot are therefore a validated subset rendered through the interpreter.

## Scope resolutions
Resolved without further user questions: Azure-first deployment; customer-hosted first release; supported real ingestion plus separate synthetic sandbox; optional lineage integrations; scoped Pro/domain ownership; shared-service reuse with consent; common action plane; Government options gated, not assumed.
Resolved by operator decision on 2026-10-08 (docs/DECISIONS-LOG.md): private repository; orchestrated-PRP kit harness; legacy demo deleted; 27 per-epic PRPs; stack pins; model policy; Commercial subscription with per-PRP live approval; Docker Compose emulators; G03 sequencing; video descoped to PRP-27; shared `packages/core`.
Customer-specific agency baseline, regions, quotas, licensing, records policies and actual write capabilities cannot be answered generically. Collect at deployment/Phase 0 rather than leave the coding agent to invent them.
Historical competitor-uniqueness, invented performance/cost percentages, Gremlin retirement claims and managed Apache AGE compatibility were not retained as facts. Prior source documents remain in git history only.
