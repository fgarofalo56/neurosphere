# PRP-32 evidence (hosted Azure demo)

This directory holds evidence for `docs/deploy/hosted-demo.md`. Files are generated by
`scripts/gates/hosted_demo.py` and `scripts/gates/hosted_demo_seed.py` after an operator-approved
live run. Nothing here is hand-written except this index. The repo is public: the scripts redact
subscription ids and run the secret scrubber before writing.

**No live step has run. Every step S1-S10 is OPEN.** A step moves out of OPEN only when its
evidence file is committed. Provider-specific live results, region availability and authorization
are separate gates and none is claimed here.

The scripts name files `<date>-<subcommand>.json` with a matching `.md`. The short names below map
to those subcommands.

| Step | What | Expected evidence | Status |
|---|---|---|---|
| S1 | preflight (read-only) | `<date>-preflight` | **OPEN** |
| S2 | plan (create tagged RG, what-if, plan hash) | `<date>-plan` | **OPEN** |
| S3 | deploy (billable plus hub-subnet, hub-pe, hub-dns, budget) | `<date>-deploy` | **OPEN** |
| S4 | grant-model-access (Foundry role) | `<date>-grant` (script name: `grant-model-access`) | **OPEN** |
| S5 | entra-redirect and user/app-role assignment | `<date>-entra` (script name: `entra-redirect`) | **OPEN** |
| S6 | seed-access --grant | `<date>-seed-access` | **OPEN** |
| S7 | seed, then seed-access --revoke | `<date>-seed` (from `hosted_demo_seed.json`, counts only) | **OPEN** |
| S8 | release tag `v0.1.0-rc.2` push, signature and digest verification | `release-v0.1.0-rc.2.md` | **OPEN** |
| S9 | smoke (automated), then manual hosted Playwright run | `<date>-smoke` | **OPEN** |
| S10 | teardown, then leftover check (`rg-ns-*`, hub PEs by tag, Entra redirect) | `<date>-teardown` | **OPEN** |

Each deploy-script evidence file records the operator, UTC time, step and approval token for every
shared-resource touch. If S4 or the copilot capability row is not approved, the copilot is
recorded as "disabled with reason".
